# Odra Documentation

Odra is a programmable text editor with a frontend-independent core and an
interactive terminal presentation. Odin owns canonical editor state and an
embedded Racket runtime provides programmable commands and configuration.

## Tutorials

The [User Guide](tutorials/user-guide/index.md) is the primary product-learning
path. It begins with the first editing session and progresses through editing,
navigation, working contexts, language intelligence, interface features, and
personal programming.

Focused product and engineering tutorials remain available from the
[Tutorials index](tutorials/index.md). They provide shorter workflow studies
and implementation-oriented traces without becoming required steps in the
User Guide.

## How-to Guides

The [How-to Guides index](how-to/index.md) contains focused procedures for a
known goal. Use it for configuration, diagnosis, file and Project operations,
language features, personal commands, and repository validation.

## Reference

The [Reference index](reference/index.md) is the exhaustive entry point for
commands, bindings, configuration, limits, lifecycle, failure, and extension
contracts. Start with [Editor Core Terminology](reference/terminology/index.md)
when an Odra concept or name is unfamiliar.

## Explanation

The [Explanation index](explanation/index.md) develops the ownership,
transaction, lifecycle, presentation, and programmability decisions behind
the editor. These documents explain why the contracts exist; they do not
replace the executable User Guide path.
