# Tutorials

Tutorials provide guided learning paths for using Odra and understanding its
architecture.

## Product Learning

The [User Guide](user-guide/index.md) is the canonical progressive path. It
starts with building and launching Odra, establishes everyday editing, and
continues through buffers, panes, search, working contexts, file management,
language intelligence, interface features, and personal programming.

Use the focused tutorials below when you need a shorter path through one
delivered workflow.

## Focused Product Tutorials

- [Undo a Semantic Terminal Edit](reversible-editing-history/index.md) groups
  ordinary typing and a local correction into one reversible unit.
- [Select Text with Point and Mark](selection/index.md) establishes, displays,
  exchanges, deactivates, and restores one region.
- [Copy, Kill, Yank, and Rotate Text](text-transfer/index.md) moves regions
  through the bounded internal ring, observes optional clipboard export, and
  reverses a yank rotation.
- [Search and Replace Text Interactively](search-and-replacement/index.md)
  searches literal text and regular expressions, confirms or skips individual
  replacements, replaces the remainder, and undoes one complete query session.
- [Start, Create, and Navigate Multiple Buffers](multiple-buffers/index.md)
  begins at the pathless startup list, keeps file-backed and named texts live,
  and uses the Buffer Menu for checked selection and marked operations.
- [Open and Navigate a Dir](dir-first-opening/index.md) opens a filesystem root
  without creating Project metadata and navigates nested files.
- [Open and Inspect a Project](project-context/index.md) exercises the retained
  one-root Project flow for promotion, Project-owned and external files,
  inspection, and reopening.
- [Inspect Local Project Authority](project-catalog/index.md) compares the
  canonical local record with global discovery and Workspace references.
- [Admit Project Configuration Safely](project-trust-refresh/index.md) grants
  exact one-root trust and publishes one confirmed configuration generation.
- [Navigate and Operate on an Active Project](project-command-workflows/index.md)
  opens Project files, switches scoped buffers, saves and closes them safely,
  and refreshes observations.
- [Work with Multiple Terminal Panes](multiple-panes/index.md) creates and
  manages nested splits while preserving pane-local presentation.
- [Navigate Commands, Buffers, and Project Files](candidate-navigation/index.md)
  uses the shared candidate interaction across common editor sources.
- [Navigate and Edit Directly](direct-navigation/index.md) uses the factory
  navigation and editing bindings for graphemes, lines, words, pages, and
  overwrite input.
- [Edit an Odin File with Factory Syntax](factory-odin-syntax/index.md) follows
  syntax presentation through ordinary editing and multiple views.
- [Navigate and Indent Odin Structure](structured-syntax-workflow/index.md)
  moves through named nodes, expands structural selection, and applies
  grammar-owned indentation.
- [Select and Inspect a Session Theme](theme-workflow/index.md) selects a
  factory theme, verifies cancellation, and returns to the safe baseline.
- [Navigate Live Language Diagnostics](language-service-workflow/index.md)
  inspects diagnostics, visits locations, observes invalidation, and contains
  service failure.
- [Read Pane Context in the Status Bar](status-bar/index.md) follows visible
  context through ordinary and narrow layouts.
- [Add a Personal Gutter Provider](programmable-gutter/index.md) publishes,
  inspects, replaces, and removes one theme-aware marker generation.

## Architecture and Integration Tutorials

- [Follow One Splice Through the Editor](editor-core/index.md) traces one text
  replacement from positions to atomic publication.
- [Trace a Multibuffer Edit Proposal](atomic-edit-transactions/index.md) follows
  a complete revision-checked proposal through shared publication.
- [Trace a Programmable and Contextual Keymap](programmable-keymaps/index.md)
  follows one Racket profile through copied records, atomic activation, and
  reload, traces prompt and contextual UI input through checked owners, and uses
  `M-x` to discover and execute native and Racket commands and inspect active
  bindings, map state, and rejected candidates.
- [Trace One UI Generation Through the Shared Pipeline](extensible-ui-system/index.md)
  follows ordinary panes and candidate navigation from their semantic owners
  through copied views, surfaces, composition, snapshots, and generic terminal
  lowering.
- [Inspect the Direct Interaction Profile](interaction-profile-compatibility/index.md)
  follows the factory catalog through profile and state selection, scoped
  bindings, canonical commands, surfaces, copied rejection, and focused
  validation without introducing another interaction grammar.
