# Search and Navigation

This part teaches incremental search, replacement, persistent result sets,
Project search, symbol navigation, and movement among active locations.

Follow these chapters in order:

1. [Search Text](search-text.md) covers incremental literal and
   regular-expression search, history, query extension, matching policy, and
   recovery.
2. [Replace Text](replace-text.md) confirms, skips, batches, scopes, and
   reverses literal and regular-expression replacements.
3. [Navigate Result Sets](navigate-results.md) materializes, filters, visits,
   refreshes, edits, applies, and closes active-buffer search results.
4. [Search Projects and Symbols](search-projects-and-symbols.md) applies the
   common result and location model across Project files and provider-neutral
   symbol indexes.

Follow the chapters in order. They progress from transient local search to
replacement, persistent result sets, Project scope, and symbols.
