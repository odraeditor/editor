# Modal Interaction

This part activates Odra's optional `modal` interaction profile and teaches its
complete factory workflow. The `direct` profile remains the default.

Start with [Work in the Modal Profile](work-in-modal-profile.md). The chapter
moves from startup selection and visible state through editing, search,
operators, Visual selection, command entry, panes, buffers, integrated
terminals, inspection, and recovery.

The tutorial uses factory bindings as a learning path. Effective personal and
contextual bindings remain discoverable through Odra's ordinary inspection
commands.
