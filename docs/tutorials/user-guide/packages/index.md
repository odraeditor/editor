# Packages and Catalogs

This part covers package discovery, installation, activation, updates,
rollback, and removal.

Follow [Use Package Catalogs](use-package-catalogs.md) to inspect the official
default, add an independent catalog, refresh confirmed state, compare curator
attribution, install and run the ROT13 canary, update and roll it back, and
recover while offline.

Continue with [Work with Local Agents](use-local-agents.md) to discover an
installed agent, start and revisit tasks, decide capability requests, manage
bounded authority, cancel work, and inspect attributable history.

After completing that lifecycle once, follow
[Build a Linked Knowledge Base with Roman](use-roman-linked-knowledge.md) to
install Odra's optional linked-knowledge package, index a Jan-backed brain,
create stable links, edit node metadata, capture notes, inspect relations, and
recover derived state.

Language bundles are one package family. After completing the generic package
lifecycle, continue with
[Manage Language Bundles](../../../how-to/manage-language-bundles/index.md) for
installation and activation.
