# Customization

This part progresses from personal startup configuration to command and
binding discovery, personal Racket commands, contextual keymaps, and supported
programmable presentation surfaces.

Follow these chapters in order:

1. [Organize Personal Configuration](personal-configuration.md) creates the
   entrypoint, separates authored settings from managed state, composes modules,
   reloads a valid generation, and recovers from rejection.
2. [Discover Commands and Bindings](discover-commands-and-bindings.md) searches
   the command catalog and explains effective resolution and availability.
3. [Use Familiar Interaction](use-familiar-interaction.md) exercises Direct
   commands, prefix arguments, component-local maps, profile separation,
   package lifecycle, and compatibility migrations.
4. [Compose Keymaps and Profiles](keymaps-and-profiles.md) activates one
   personal binding, remap, and mask and recovers from protected overlap.
5. [Write and Reload a Personal Command](personal-commands.md) defines, binds,
   invokes, inspects, replaces, bounds, and recovers one Racket text command.
6. [Extend Ksawery from Personal Configuration](extend-ksawery.md) declares,
   loads, exercises, inspects, disables, and recovers one complete personal
   repository contributor.
7. [Configure Visible Behavior](configure-visible-behavior.md) maps themes,
   Status Bar, Gutter, completion, commands, keymaps, search, panes, and
   transient presentation to their current supported boundaries.
