# Buffers and Panes

This part teaches how Odra keeps several texts live and presents them through
independent panes and restorable layouts.

Follow these chapters in order:

1. [Work with Buffers](work-with-buffers.md) creates, opens, switches,
   inspects, saves, and closes a live working set.
2. [Arrange Panes](arrange-panes.md) builds, focuses, resizes, balances, and
   reduces a nested pane layout.
3. [Understand Pane-Local State](understand-pane-state.md) contrasts shared
   text with independent view history and selecting versus display-only
   placement.
4. [Restore Layouts](restore-layouts.md) persists portable pane topology,
   targets, and focus while leaving buffer contents untouched.
5. [Use Integrated Terminals](integrated-terminals.md) creates independent
   shell sessions, presents them through ordinary panes, and returns safely to
   editing.

Follow the chapters in order. They progress from the live buffer set to
visible composition, pane-local presentation, and persistent layout intent.
