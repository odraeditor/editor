# Darek

Darek keeps a persistent filesystem tree beside ordinary editing panes. This
module teaches tree navigation first, then file placement and preview, and
finally validated filesystem changes.

Complete [Manage a Workspace](../manage-a-workspace.md) first. The maintained
`User Guide` Workspace provides two Project roots and enough nested content to
exercise every chapter in disposable files outside the Odra repository.

## In This Module

1. [Browse Trees](browse-trees.md) shows Darek, moves through a Dir, Project,
   or Workspace tree, and changes the visible root without changing durable
   Project or Workspace state.
2. [Preview and Open Files](preview-and-open.md) visits files in existing or
   new panes, previews without leaving the tree, follows active files, and
   adjusts the panel.
3. [Manage Resources](manage-resources.md) creates, renames, moves, copies,
   identifies, and permanently removes disposable filesystem resources.
4. [Use Contextual Operations](use-contextual-operations.md) browses document
   symbols, runs shell commands from selected roots, delegates bulk work to
   Maksym, and discovers commands from the current node.

For the exact command inventory, bindings, bounds, and ownership model, see
the [Darek Reference](../../../../reference/darek/index.md).
