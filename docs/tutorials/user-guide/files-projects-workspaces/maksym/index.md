# Maksym

Maksym presents one directory as a navigable listing whose filename fields can
be edited as ordinary text before any filesystem change occurs. This module
teaches observation first, edit preparation second, and validated publication
last.

Complete the [Darek module](../darek/index.md) first. The same maintained
`User Guide` Workspace provides familiar disposable content for comparing a
persistent tree with an editable directory listing.

## In This Module

1. [Browse Directory Listings](browse-directory-listings.md) opens Maksym in
   active or split panes, navigates directories and entries, reads metadata,
   changes presentation, and refreshes observed truth.
2. [Edit Filenames](edit-filenames.md) enters the editable projection, prepares
   renames and relative moves as text, preserves directory semantics, and
   cancels without changing source resources.
3. [Apply Filesystem Changes](apply-filesystem-changes.md) validates and applies
   one prepared revision, demonstrates collision rejection and supported
   permanent deletion, and cleans up the disposable exercise.

For the exact command inventory, bounds, and ownership model, see the
[Maksym Reference](../../../../reference/maksym/index.md).
