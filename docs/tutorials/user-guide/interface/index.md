# Interface

This part teaches how to interpret and configure the editor's visible context,
including themes, the Status Bar, the Gutter, transient detail surfaces, and
semantic feedback.

Follow these chapters in order:

1. [Select and Read a Theme](themes.md) selects and inspects one complete
   session theme, reads active context, and observes narrow and reduced-color
   presentation.
2. [Read and Configure the Status Bar](status-bar.md) interprets pane-local
   safety, position, Project, Workspace, and language context, invokes admitted
   actions, and changes the layout policy.
3. [Use the Gutter](gutter-and-transient-details.md) reads line numbering,
   semantic markers, transient details, and admitted actions.
4. [Read Feedback and Progress](read-feedback-and-progress.md) interprets
   command outcomes, attention, measured work, actions, and fallback behavior.
