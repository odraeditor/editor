# Choose an Installation Method

Start here to choose a published, verified way to install Odra. Complete one
method before continuing with the rest of Getting Started; later chapters use
the same installed editor regardless of how you obtained it.

## Available Methods

### Linux x86-64 preview package

Use the [manual Linux package procedure](install-linux-preview.md) on a Linux
x86-64 system with a UTF-8 terminal. It downloads an immutable published
preview, verifies its checksum, and runs without a source checkout or an
installed Racket runtime.

This is currently the only installation method in the User Guide.

## Choose a Method

Use a method only when it appears under Available Methods. An absent method
does not yet have both a published package and a verified reader procedure, so
the User Guide does not present it as an executable installation route.

When another package method becomes available, it will appear beside the Linux
preview route on this page. The chapters after installation will continue from
the same installed-command boundary.

## Continue

Follow [Install and Launch a Linux Preview](install-linux-preview.md), then
return to the Getting Started sequence.
