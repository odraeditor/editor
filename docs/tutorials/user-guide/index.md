# User Guide

This guide documents Odra v0.2.0. For the product overview and project entry
point, visit the [Odra website](https://odraeditor.org/).

The User Guide is the progressive path from a first Odra session to confident
editing and personal programming. Follow the parts in order when learning the
editor, or enter a part directly when returning to a known workflow.

## Start Here

[Getting Started](getting-started/index.md) installs and launches an immutable
Linux preview, prepares isolated exercises, opens and saves the first file,
and introduces commands, prompts, candidates, acceptance, cancellation, and
help. Begin with
[Choose an Installation Method](getting-started/install-odra.md).

## Learning Path

1. [Getting Started](getting-started/index.md)
   establishes the first complete editing session and the interaction grammar
   used throughout the guide.
2. [Editing](editing/index.md)
   covers movement, selection, text transfer, reversible history, and named
   editor state.
3. [Buffers and Panes](buffers-and-panes/index.md)
   develops a live working set and arranges it across independent views.
4. [Search and Navigation](search-and-navigation/index.md)
   moves from incremental search to replacement, result sets, Project search,
   and symbols.
5. [Files, Projects, and Workspaces](files-projects-workspaces/index.md)
   introduces Odra's working contexts and the Darek and Maksym file-management
   modules.
6. [Language Intelligence](language-intelligence/index.md)
   uses syntax, structure, Jan documents, maintained and configured language
   services, diagnostics, completion, and graceful provider fallback.
7. [Structured Documents](structured-documents/index.md)
   develops Jan from ordinary editing into planning, computation, export,
   publishing, provider use, extensions, and failure recovery.
8. [Packages and Catalogs](packages/index.md)
   discovers official and independent catalogs, compares curator attribution,
   uses exact manual sources, and recovers confirmed state offline.
9. [Interface](interface/index.md)
   explains themes, the Status Bar, the Gutter, transient presentation,
   feedback, and progress.
10. [Customization](customization/index.md)
   progresses from personal configuration to commands, keymaps, Ksawery
   contributors, and visible programmable surfaces.
11. [Modal Interaction](modal-interaction/index.md)
   activates the optional modal profile and completes its editing, command,
   pane, buffer, terminal, inspection, and recovery workflow.

## Direct Routes

- For first use, begin with
  [Getting Started](getting-started/index.md).
- For file management, begin with
  [Files, Projects, and Workspaces](files-projects-workspaces/index.md).
- For repository Status, history, commits, and complete-path stage or unstage, open
  [Manage Repository Changes with Ksawery](files-projects-workspaces/manage-changes-with-ksawery.md).
- For the persistent tree panel, open the
  [Darek module](files-projects-workspaces/darek/index.md).
- For editable directory listings, open the
  [Maksym module](files-projects-workspaces/maksym/index.md).
- For semantic candidates, open
  [Use Language Completion](language-intelligence/language-completion.md).
- To use maintained Go syntax and its external language service, open
  [Use Factory Go Language Support](language-intelligence/configure-language-support.md).
- To exercise the complete shipped language baseline, open
  [Use the Basic Language Pack](language-intelligence/use-the-basic-language-pack.md).
- For compatible `.org` and `.jan` document analysis, open
  [Work with Jan Documents](language-intelligence/work-with-jan-documents.md).
- For Jan planning, computation, output, providers, and recovery, begin with
  [Structured Documents](structured-documents/index.md).
- For the complete syntax, diagnostics, and completion path, begin with
  [Language Intelligence](language-intelligence/index.md).
- For curated and manual package discovery, begin with
  [Packages and Catalogs](packages/index.md).
- For direct agent tasks, authority decisions, cancellation, and audit, open
  [Work with Local Agents](packages/use-local-agents.md).
- For a Jan-backed linked knowledge base, open
  [Build a Linked Knowledge Base with Roman](packages/use-roman-linked-knowledge.md).
- For line numbers and markers, open
  [Use the Gutter](interface/gutter-and-transient-details.md).
- For command outcomes, progress, attention, and checked actions, open
  [Read Feedback and Progress](interface/read-feedback-and-progress.md).
- For personal configuration and programming, begin with
  [Customization](customization/index.md).
- For the optional stateful keyboard profile, open
  [Modal Interaction](modal-interaction/index.md).
- For exact public terminology, use the
  [Editor Core Terminology](../../reference/terminology/index.md).

The guide teaches workflows. Focused procedures remain under
