# Command and Keybinding Reference

This appendix lists the public commands shipped by Odra and its baseline
official packages. It records factory bindings; `M-x only` means that a
command is available by name but has no factory key sequence.

Personal configuration and installed packages can change the active catalog.
Use `describe-bindings`, `describe-key`, and `where-is` for the current
session. Module references remain authoritative for complete behavior and
failure semantics.
